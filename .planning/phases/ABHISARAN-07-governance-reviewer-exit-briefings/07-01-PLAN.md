# Plan 07-01: Delivery Point Exit Briefing Workflow (GOVN-01)

## Overview
Implement the delivery point exit briefing workflow (AEHT §14.1) recording factual observations, institution head acknowledgement, or non-adverse refusal reasons. Crucially enforce the invariant: refusal or unsigned status is **never** adverse evidence and never counts as a dispute or penalty.

## Requirements
- **GOVN-01**: Delivery point exit briefing workflow recording factual observations, signatures, or non-adverse refusal.

## Proposed Changes

### 1. Database Schema
- Create `backend/src/main/resources/db/migration/V8__governance_and_reviews.sql`:
  - `exit_briefings` table with status (`ACKNOWLEDGED`, `SHARED_UNSIGNED`, `REFUSED_NON_ADVERSE`), acknowledgement text, refusal reasons, factual discrepancy notes, material correction flag, correction window timestamp, and finalization flag.
  - `factual_corrections` table for immutable corrections.
  - `reviewer_declarations` table for independent reviewer pack.
  - Seed initial exit briefings for pilot delivery points demonstrating acknowledged and non-adverse unsigned scenarios.

### 2. Backend Domain & Logic
- Create `ExitBriefing.java` entity in `org.aeht.abhisaran.model`.
- Create `ExitBriefingRepository.java` in `org.aeht.abhisaran.repository`.
- Create `ExitBriefingService.java` in `org.aeht.abhisaran.governance`:
  - Business invariant: `exit-briefing unsigned ≠ adverse`. An unsigned or refused briefing cannot alter ACS scores, components, or gap status.
  - Enforce mandatory recording of refusal reasons if unsigned.
  - Compute correction window status (open vs closed).
- Create `ExitBriefingController.java` exposing:
  - `GET /api/v1/governance/exit-briefings`
  - `GET /api/v1/governance/exit-briefings/{dpCode}`
  - `POST /api/v1/governance/exit-briefings`
  - `PATCH /api/v1/governance/exit-briefings/{id}/finalize`

### 3. Verification
- Create `ExitBriefingTests.java` validating:
  - Unsigned briefing preserves non-adverse semantics.
  - Validation requires reason when status is `SHARED_UNSIGNED` or `REFUSED_NON_ADVERSE`.
  - Finalization closes correction window.
