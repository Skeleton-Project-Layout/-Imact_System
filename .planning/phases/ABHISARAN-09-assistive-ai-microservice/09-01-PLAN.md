# Plan 09-01: Assistive AI FastAPI Microservice Endpoints (AIMS-01)

## Overview
Implement the Python FastAPI assistive microservice with dedicated endpoints for permitted document OCR text extraction, multi-pattern Zero-PII pre-screening, and assistive draft action brief generation from verified evidence.

## Requirements
- **AIMS-01**: Python FastAPI service restricted to OCR text extraction, PII pre-check, and drafting action briefs.

## Proposed Changes

### 1. AI Service Implementation (`ai-service/main.py`)
- Enhance endpoints:
  - `POST /api/v1/ocr-extract`: Extracts text from permitted document kinds (`PROCESS_DOCUMENT`, `WALL_DISPLAY`, `INFRASTRUCTURE`, `REGISTER_EXTRACT`), automatically runs PII screening, and redacts any suspected numbers.
  - `POST /api/v1/pii-check`: Evaluates text for Aadhaar, phone numbers, and personal names.
  - `POST /api/v1/draft-brief`: Generates plain-language action briefs strictly from verified evidence IDs. Stores metadata: `model_id`, `timestamp`, `input_evidence_refs`, `quality_metadata`, and mandatory status `DRAFT`.
  - `POST /api/v1/summarize-observations`: Groups and explains verified observations in non-punitive system language.

### 2. Verification
- Author test suite in `ai-service/test_main.py` verifying all endpoints, PII detection accuracy, and mandatory `DRAFT` status enforcement.
