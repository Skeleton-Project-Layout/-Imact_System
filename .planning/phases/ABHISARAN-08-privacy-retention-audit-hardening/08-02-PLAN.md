# Plan 08-02: 30-Day Retention Countdown, Deletion Certificate & Append-Only Audit Logging (SEC-02, SEC-03, SEC-04)

## Overview
Implement the 30-day post-handover retention countdown, candidate data purging workflow, formal Deletion Certificate generator for the District Nodal Officer, and append-only audit logging for all critical governance decisions.

## Requirements
- **SEC-02**: 30-day post-handover retention countdown with automated deletion candidate list.
- **SEC-03**: Deletion certificate generator produced for District Nodal Officer.
- **SEC-04**: Append-only audit logging capturing who, what, when, previous/new states, reason, and rule version.

## Proposed Changes

### 1. Database Schema
- Create `backend/src/main/resources/db/migration/V9__retention_and_deletion.sql`:
  - `retention_schedules` table tracking handover date, 30-day target purge date, days remaining, and written extension references.
  - `deletion_certificates` table storing certificate serial numbers, SHA-256 proof hashes, recipient DNO details, and purged record tallies.
  - Seed initial pilot retention schedule starting from Day 7 handover.

### 2. Backend Domain & Logic
- Create `RetentionSchedule.java`, `DeletionCertificate.java`, and `AuditLog.java` JPA entities.
- Create repositories `RetentionScheduleRepository.java`, `DeletionCertificateRepository.java`, and `AuditLogRepository.java`.
- Create `RetentionService.java`:
  - Calculates retention countdown (30 days from Day 7 handover).
  - Identifies purging candidates.
  - Executes purge and produces an immutable, SHA-256 hashed `DeletionCertificate`.
- Create `AuditLogService.java`:
  - Logs critical state changes (scores, verifications, corrections, incidents, deletions) to the append-only `audit_logs` table.
- Create REST controllers:
  - `RetentionController.java` (`/api/v1/privacy/retention`)
  - `AuditLogController.java` (`/api/v1/admin/audit-logs`)

### 3. Frontend Views
- Create `PrivacyIncidentsView.jsx`: 2-hour countdown badge, 5-stage progression tracker, and incident containment logs.
- Create `RetentionAndAuditView.jsx`: 30-day retention countdown, Deletion Certificate viewer, and append-only audit log.
- Wire views into `AdminShell.jsx`.

### 4. Verification
- Create `RetentionServiceTests.java` and `AuditLogTests.java`.
- Build frontend with `npm run build` to verify clean compilation.
