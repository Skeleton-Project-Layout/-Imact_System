# ABHISARAN Assistive AI Microservice

## Architectural Invariants (AEHT §3.4 & §12)

1. **Strictly Assistive**: The AI microservice assists only with optical character recognition (OCR), text pre-screening for suspected PII, and drafting plain-language action briefs from already-verified structured inputs.
2. **Zero Write Permissions**: The AI service has **no write path** to:
   - Aryabhata Continuity Scores (ACS)
   - Component scores
   - Gap verification statuses
   - Severity, Urgency, Reach, or Feasibility ratings
   - System flags or official recommendations
3. **Draft Status**: All text output generated by this service carries `status: DRAFT` and requires explicit human review and acceptance before entering official records.
4. **Zero-PII Input**: The microservice receives only pre-screened text. Any suspected PII immediately halts processing and triggers a `PrivacyIncident` in the backend.
